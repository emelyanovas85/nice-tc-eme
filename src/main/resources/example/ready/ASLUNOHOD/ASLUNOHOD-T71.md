### 3.4 Вывод и рекомендации

**Основная проблема:**
Тест-кейс **ASLUNOHOD-T71** в текущем виде **не готов к автоматизации** из-за низкой детерминированности шагов и некорректно сформулированных ожидаемых результатов.
Ключевые нарушения:
1.  **Отсутствие параметризации:** Шаги 3, 5, 6, 7 содержат неопределенные действия ("выбрать необходимый", "ввести запрос"), что не позволяет скрипту выполнить их без ручного вмешательства.
2.  **Некорректные проверки (Assertions):** Ожидаемые результаты дублируют действия ("выбрано", "введено") вместо проверки состояния конкретных UI-элементов (наличие текста в поле, статус чек-бокса). Шаг 8 ожидает недетерминированный контент (текст ответа ИИ), что приведет к нестабильности тестов.
3.  **Логические ветвления:** Наличие условия "При необходимости" в шаге 4 нарушает линейность выполнения автотеста.
4.  **Статус и предварительные условия:** ТК имеет статус "Draft" и не описывает проверку начального состояния системы (отсутствие дублей), что критично для идемпотентности тестов.

**Рекомендации по устранению:**
1.  **Параметризовать данные:** Вынести все переменные значения (Компонент ИТС, Модель ИИ, Тип использования, Текст запроса) в блок "Параметры" или "Наборы тестовых данных". Переформулировать шаги с использованием плейсхолдеров (например, `{Модель_ИИ}`).
2.  **Детализировать Ожидаемые Результаты:** Для каждого шага переписать ОР, указывая:
    *   Тип элемента (поле ввода, выпадающий список, чек-бокс, таблица).
    *   Наименование элемента (лейбл, заголовок).
    *   Ожидаемое состояние (текст равен..., элемент видим, чек-бокс отмечен).
    *   Для шага с ответом ИИ проверять только факт появления ответа и статус успеха, игнорируя содержание текста.
3.  **Устранить ветвления:** Удалить фразу "При необходимости" из шага 4. Сделать шаг обязательным с передачей пустого значения или конкретного URL через параметр.
4.  **Исправить метаданные:** Изменить статус ТК на "Утвержден" или "АТ принят". Добавить в предварительные действия проверку через API/БД на отсутствие конфликтующих данных перед запуском теста.
5.  **Расшифровать термины:** Заменить аббревиатуры (ИТС, АТК) на полные названия или добавить пояснения в контексте шагов.
