## 4. Вывод и рекомендации

**Рекомендации по устранению:**
1.  **Изоляция данных:** Добавить шаги или использовать фикстуры для программного создания тестовых данных (ИИ ТК и файл «Типовой ТК») внутри теста. Исключить ручную подготовку.
