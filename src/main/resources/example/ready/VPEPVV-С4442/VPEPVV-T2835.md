## 4. Вывод и рекомендации

**Основная проблема:**
Тест-кейс **VPEPVV-T2835** категорически не готов к автоматизации в текущем виде. Главная причина — нарушение принципа **Единой ответственности** и **Атомарности**. В одном тест-кейсе объединены **6 различных негативных сценариев** проверки валидации (отсутствие файлов, чужая подпись, шифрование и т.д.). Это делает тест нечитаемым для автоматизации, недетерминированным (непонятно, какая именно проверка упала) и сложным в поддержке.

Дополнительные критические проблемы:
1.  **Нарушение структуры шагов:** Шаги содержат логические ветвления ("В случае..."), смешанные инструкции для ручного и автоматизированного тестирования ("Для РТ...", "Для АТ..."), а также вызовы других тест-кейсов внутри описания действий.
2.  **Проблемы с данными и вложениями:** Файлы, необходимые для выполнения шагов (.sig, .enc), отсутствуют во вложениях. Эталонные файлы для сравнения указаны в данных, но физически не приложены. В шагах используются жестко заданные имена файлов, игнорирующие параметризацию.
3.  **Статус и документация:** Тест-кейс не имеет требуемых статусов ("Утвержден", "АТ принят") и не имеет записей о успешном прохождении, что блокирует его включение в регрессионные прогоны.
4.  **Вложенный ТК (VPEPVV-T2358):** Содержит запрещенные для вложенных кейсов блоки "Предварительные действия" и "Наборы тестовых данных", а также использует предметный жаргон ("плитка", "ФЛ(ХМЧД)") без пояснений.

**Рекомендации по устранению:**
1.  **Декомпозиция:** Разделить тест-кейс **VPEPVV-T2835** на **6 отдельных тест-кейсов**, каждый из которых проверяет одну конкретную причину ошибки (например, "Ошибка при отправке без файлов отчетности", "Ошибка при отправке с чужой ЭП" и т.д.).
2.  **Очистка шагов:** Удалить из шагов все условия ("В случае..."), инструкции для ручного тестирования и ссылки на другие ТК. Описать действия атомарно и линейно.
3.  **Работа с данными:**
    *   Добавить все недостающие файлы (.sig, .enc, .xml) во вложения тест-кейса.
    *   Удалить лишние файлы.
    *   Настроить корректную параметризацию: имена файлов в шагах должны соответствовать колонкам в "Наборах тестовых данных".
    *   Вынести действие добавления сертификата (вложенный ТК) в отдельный шаг или в фикстуры подготовки теста.
